# Gone Phishing

Source for [gonephishing.org](https://gonephishing.org) — a free educational site about social engineering and phishing.

The site is built with [Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages. You do not need to install anything to write a new post or guide — just add a Markdown file and push it. See [CONTRIBUTING.md](CONTRIBUTING.md) for exact instructions.

## Previewing changes locally (optional)

If you want to see your changes before they go live:

```
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000 in your browser. This step is optional — GitHub builds and publishes the site automatically a minute or two after you push, whether or not you preview locally.
